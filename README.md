
# Cybersecurity Portfolio — Rahmeen Khan

SOC Analyst Track intern at the National Centre for Cyber Security (NCCS), NED University of Engineering & Technology, working under Team Lead Sheikh Abdul Basit. Telecommunications Engineering student combining network/systems fundamentals with hands-on security analysis.

This repo documents hands-on detection engineering and malware analysis work completed during the internship — phishing investigation, static and dynamic malware analysis, infostealer family research, SIEM deployment, and layered threat detection simulations.

## Skills & Tools

- **Malware Analysis:** static & dynamic analysis, payload retrieval, reverse engineering Windows binaries (Ghidra, Detect It Easy)
- **Detection Engineering:** YARA rule testing, ClamAV signature scanning, Suricata (Emerging Threats ruleset), anomaly-based filesystem hunting
- **SIEM:** Wazuh deployment, alert rule creation, pattern-based detection
- **Phishing/Email Forensics:** `.eml` header parsing, payload extraction, IOC identification
- **Environment:** Kali Linux, Nmap, Metasploit
- **Other:** off-grid communication channel research
